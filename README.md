# Cloud9 x JetBrains: Sky's The Limit — Kategori 3 (Event Mini Game)

Dua kandidat mini game booth Cloud9, dibangun dengan JetBrains tools. Repo ini masih tahap prototype — pemenang pairwise akan dibangun jadi entry final.

- **Kandidat A — Sky Aim:** flick & reaction trainer. Blitz 60 detik + Reaction Sprint 10 ronde. Main: [prototypes/sky-aim/index.html](https://naplex666.github.io/cloud9-sky-aim/prototypes/sky-aim/)
- **Kandidat B — Sky Stack:** timing stacking satu tombol. Main: [prototypes/sky-stack/index.html](https://naplex666.github.io/cloud9-sky-aim/prototypes/sky-stack/)

## Cara main (prototype)
Buka link di atas di browser HP / desktop. Tanpa install, tanpa login, tanpa Wi-Fi sesudah load. Skor tersimpan lokal (localStorage).
